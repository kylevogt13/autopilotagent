# Autopilot Agent  -  Internal Setup Checklist

*Use this checklist for every new $997 Autopilot Agent customer. Target: complete setup within 5 business days of intake form submission.*

---

## Phase 1: Intake & Account Setup (Day 0–1)

- [ ] Intake form received and reviewed
- [ ] Customer record created in CRM/tracking sheet
- [ ] Email 2 (Setup Kickoff) sent automatically
- [ ] Flag any incomplete or unclear intake responses  -  follow up within 24 hours
- [ ] Assign internal setup owner for this customer

## Phase 2: Brand & Content Configuration (Day 1–3)

- [ ] Review brand voice answers (Q13–16) and create voice profile
- [ ] Set up content AI with:
  - [ ] Target area(s) and property types
  - [ ] Brand tone and language preferences
  - [ ] Topics to avoid / competitor restrictions
- [ ] Connect social media accounts (Q18–19)
- [ ] Generate first batch of sample content (3–5 posts)
- [ ] Internal QA: Does the content sound like the agent? Match the brand?
- [ ] If brand assets provided (logo, colors), integrate into templates

## Phase 3: Lead Follow-Up Configuration (Day 2–4)

- [ ] Identify lead sources (Q23)
- [ ] Connect to CRM if applicable (Q24)
- [ ] Build automated follow-up sequences:
  - [ ] New lead welcome/response (immediate)
  - [ ] Day 1 follow-up
  - [ ] Day 3 follow-up
  - [ ] Day 7 follow-up
  - [ ] Long-term nurture (monthly)
- [ ] Customize sequence language to match agent's voice
- [ ] Test: Send test lead through the full sequence

## Phase 4: Admin & Workflow Automation (Day 2–4)

- [ ] Review admin pain points (Q27–29)
- [ ] Configure relevant automations:
  - [ ] Scheduling automation (if applicable)
  - [ ] Document workflow automation (if applicable)
  - [ ] Custom workflows requested by agent
- [ ] Test each automation end-to-end

## Phase 5: Quality Assurance (Day 4)

- [ ] Full review of all configured systems
- [ ] Content QA: Review 5+ generated posts for voice accuracy
- [ ] Lead follow-up QA: Run test lead through full sequence
- [ ] Automation QA: Trigger each workflow and verify output
- [ ] Dashboard/portal configured and accessible
- [ ] Internal sign-off: Setup owner approves go-live

## Phase 6: Go-Live (Day 5)

- [ ] Send Email 3 (Go-Live email) with dashboard link and checklist
- [ ] Send calendar link for Go-Live Call
- [ ] Conduct Go-Live Call (15–20 min):
  - [ ] Walk through dashboard
  - [ ] Show content calendar and first scheduled posts
  - [ ] Demo lead follow-up sequence
  - [ ] Show admin automations
  - [ ] Answer questions
- [ ] Confirm customer can access everything
- [ ] Mark setup as **complete** in tracking sheet

## Phase 7: Post-Launch Check-In (Day 7–14)

- [ ] Day 7: Check  -  has first AI content been posted?
- [ ] Day 7: Check  -  has at least one lead received automated follow-up?
- [ ] Day 10: Send check-in email ("How's everything running?")
- [ ] Day 14: Review success metrics (see Success Criteria doc)
- [ ] Flag any issues or customer concerns for immediate resolution
- [ ] If customer is not engaged, escalate to Kyle

---

## Notes

- **SLA:** Intake form → Go-live in ≤5 business days
- **Escalation:** If blocked on CRM access, missing info, or technical issues, escalate same-day
- **Customer comms:** Keep the customer informed at every stage  -  silence breeds doubt
